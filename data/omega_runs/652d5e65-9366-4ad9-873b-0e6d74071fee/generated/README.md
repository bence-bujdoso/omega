# acropolis-athens

A single self-contained Three.js scene generated by the Omega Framework pipeline.

## Run

Just open `index.html` in any modern browser — no build step, no server required.
All dependencies load from a pinned CDN via an ES module import map.

## Controls
- **Time of day** slider: morning -> high noon -> golden hour (sun angle, colour temperature and shadow softness change)
- **Haze** slider: distance haze density
- **Crowd** toggle + **density** slider: instanced robed figures for scale
- **Camera**: Classic postcard (default) · Close inspection · Flyover path

## Notes
- Instanced olive trees and people for performance
- Device pixel ratio clamped below 2; target ~55 FPS
- Subtle procedural marble tint on the Parthenon
